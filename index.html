Questions fréquentes

Quel format de numéro dois-je utiliser ?

Le numéro complet avec l'indicatif du pays, sans le 0 de tête, sans espaces et sans le signe +. Exemple : 243812345678.

Où dois-je saisir le code ?

Dans WhatsApp, ouvre Paramètres › Appareils connectés › Connecter un appareil, puis choisis « Connecter avec un numéro de téléphone » et entre le code.

Le code ne fonctionne pas, que faire ?

Vérifie ton numéro, génère un nouveau code et saisis-le rapidement. Si le souci continue, écris au propriétaire depuis le menu (OWNER CONTACT).

Comment déconnecter le bot ?

Ouvre WhatsApp › Paramètres › Appareils connectés, touche l'appareil du bot, puis choisis Se déconnecter. Tu peux le faire quand tu veux.
